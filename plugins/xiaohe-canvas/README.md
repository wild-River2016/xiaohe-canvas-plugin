# 小禾画布 Codex 插件

让 Codex 可以打开并操作[小禾画布](https://www.xiaohe.store/)。

## 安装

```bash
# 添加插件市场
codex plugin marketplace add https://github.com/wild-River2016/xiaohe-canvas-plugin

# 安装插件
codex plugin add xiaohe-canvas
```

## 使用

在 Codex 对话中输入：

```text
打开小禾画布
```

或者直接描述你的需求：

```text
我是淘宝店主，卖童装，想做宣传视频
```
