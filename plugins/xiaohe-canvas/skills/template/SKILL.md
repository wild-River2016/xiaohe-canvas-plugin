# 画布模板库

你可以通过模板检索工具帮助用户找到适合他们需求的画布模板。模板库包含电商带货、服装穿搭、室内家居、人像写真、短视频创意等多种类型。

## 工作流

### 1. 理解用户需求

当用户想要创作但不知道从何开始时，先通过对话了解：
- 想做什么类型的内容？（产品图、短视频、人像照等）
- 用于什么场景？（电商、社交媒体、个人创作等）
- 有什么素材？（产品图、模特照、效果图等）

### 2. 搜索匹配模板

使用 `templates_search` 搜索合适的模板：

```
# 全文搜索
templates_search({ query: "电商产品主图" })

# 按标签过滤
templates_search({ tags: ["服装", "带货"] })

# 按分类浏览
templates_search({ category: "电商带货" })

# 组合搜索
templates_search({ query: "羽绒服", category: "服装穿搭", limit: 5 })
```

### 3. 推荐模板

向用户展示匹配的模板时，说明：
- 模板名称和用途
- 需要用户准备什么素材（inputRequirements）
- 最终会输出什么（outputType：图片/视频/混合）
- 模板的工作流程概述

### 4. 使用模板

用户选择模板后，有两种使用方式：

#### 方式一：直接导入

使用 `templates_import_to_canvas` 将模板导入当前画布：
- 会自动转换格式并创建所有节点和连线
- 用户可以直接替换占位素材
- 适合想快速开始的用户

#### 方式二：参考创作

使用 `templates_get` 获取模板详情，包含完整的画布结构（graph）：
- 分析模板的节点结构和提示词写法
- 参考工作流设计，为用户创建定制化的画布
- 适合有特殊需求的用户

## 模板分类

| 分类 | 描述 | 典型模板 |
|------|------|---------|
| 电商带货 | 电商产品展示、带货视频 | 产品主图、详情页、直播切片 |
| 服装穿搭 | 服装展示、换装、穿搭视频 | 模特换装、服装转场、穿搭展示 |
| 室内家居 | 家装效果图、室内漫游 | 装修效果图、家居短视频、空间展示 |
| 人像写真 | 人像拍摄、艺术照 | 写真视频、人物特写、氛围照 |
| 短视频创意 | 创意短视频、转场特效 | 颜色转场、创意剪辑、故事板 |
| 产品展示 | 产品拍摄、商品展示 | 产品视频、3D展示、细节特写 |
| 户外场景 | 户外拍摄、场景展示 | 雪山、海边、城市街拍 |
| 美食摄影 | 美食拍摄、餐饮展示 | 美食视频、菜品图、餐厅氛围 |
| 分镜脚本 | 视频分镜、故事板 | 九宫格分镜、时间线脚本 |

## 对话引导示例

**用户**：帮我做个电商主图

**助手**：好的，我帮你找找适合的模板。请问：
1. 是什么产品？（服装、护肤品、数码产品等）
2. 需要什么风格？（简约白底、场景图、创意图）
3. 你现在有产品图吗？

**用户**：羽绒服，想要户外场景，有产品平铺图

**助手**：我找到几个适合的模板：
1. **羽绒服雪山展示** - 把产品放到雪山户外场景，突出保暖卖点
2. **服装户外街拍** - 模特穿着产品在街头拍摄
3. **产品场景融合** - 产品图自动融入户外背景

你想用哪个？或者我可以参考这些模板为你定制一个工作流。

## 注意事项

1. 模板服务需要已部署并运行（Template API）
2. 模板中的媒体 URL 来自原始平台，可能无法直接使用
3. 导入后建议用户检查并替换占位素材
4. 便签节点包含使用说明，不要删除
